# Android File Upload Error Codes

Reference the error codes returned during file upload.

| Error code | Description |
|-|-|
| 0 | Success |
| 1 | SVC handler is missing |
| 2 | SoftDevice has not been enabled |
| 3 | Internal Error |
| 4 | No Memory for operation |
| 5 | Not found |
| 6 | Not supported |
| 7 | Invalid Parameter |
| 8 | Invalid state |
| 9 | Invalid Length |
| 10 | Invalid Flags |
| 11 | Invalid Data |
| 12 | Invalid Data size |
| 13 | Operation timed out |
| 14 | Null Pointer |
| 15 | Forbidden Operation |
