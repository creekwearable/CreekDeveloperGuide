# iOS File Upload Error Codes

## Overview

Handle file-upload callback errors according to the table below. These numeric values come from the SDK file-upload error-code definition.

| Code | Meaning |
|---:|---|
| 0 | Success |
| 1 | SVC handler is missing |
| 2 | SoftDevice has not been enabled |
| 3 | Internal error |
| 4 | Not enough memory for the operation |
| 5 | Not found |
| 6 | Not supported |
| 7 | Invalid parameter |
| 8 | Invalid state |
| 9 | Invalid length |
| 10 | Invalid flags |
| 11 | Invalid data |
| 12 | Invalid data size |
| 13 | Operation timed out |
| 14 | Null pointer |
| 15 | Forbidden operation |
