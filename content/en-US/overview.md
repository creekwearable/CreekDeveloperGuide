# Creek Developer Guide

Welcome to the Creek developer documentation. Find SDK integration guides for Android, iOS, Flutter, and HarmonyOS here.

## Choose a platform

- Android: for Kotlin and Java projects
- iOS: for Swift and Objective-C projects
- Flutter: for cross-platform Dart projects
- HarmonyOS: for ArkTS projects

## Integration flow

1. Select your development platform.
2. Follow the quick start to install and initialize the SDK.
3. Configure app permissions and connect a device.
4. Use the feature guides to call the APIs you need.

## Documentation language

Use the language control in the upper-right corner to switch between 中文 and English. Your selected platform is preserved when you switch languages.
