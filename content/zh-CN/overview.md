# Creek 开发者指南

欢迎使用 Creek 开发者文档。你可以在这里查找 Android、iOS、Flutter 和 HarmonyOS 的 SDK 接入说明。

## 选择开发平台

- Android：适用于 Kotlin 和 Java 项目
- iOS：适用于 Swift 和 Objective-C 项目
- Flutter：适用于 Dart 跨平台项目
- HarmonyOS：适用于 ArkTS 项目

## 接入流程

1. 选择对应的开发平台。
2. 按照快速开始完成 SDK 安装和初始化。
3. 配置应用权限并连接设备。
4. 根据功能指南调用所需接口。
