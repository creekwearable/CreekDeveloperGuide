# iOS 文件上传错误码

## 功能说明

文件上传回调中的错误码按下表处理。这些数值来自 SDK 文件上传错误码定义。

| 错误码 | 含义 |
|---:|---|
| 0 | 成功 |
| 1 | 缺少 SVC 处理器 |
| 2 | SoftDevice 未启用 |
| 3 | 内部错误 |
| 4 | 操作内存不足 |
| 5 | 未找到 |
| 6 | 不支持 |
| 7 | 参数无效 |
| 8 | 状态无效 |
| 9 | 长度无效 |
| 10 | 标志位无效 |
| 11 | 数据无效 |
| 12 | 数据大小无效 |
| 13 | 操作超时 |
| 14 | 空指针 |
| 15 | 禁止执行该操作 |
